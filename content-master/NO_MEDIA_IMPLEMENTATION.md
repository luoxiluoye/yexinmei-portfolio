# NO MEDIA IMPLEMENTATION RULE

Quest Detail 在没有真实项目媒体时：

1. `gallery.length === 0` 时完全隐藏 Gallery section。
2. 不显示：
   - REAL PROJECT COVER PENDING
   - IMAGE PENDING
   - PLACEHOLDER
   - 灰色空框
   - 虚构截图
3. Hero 若原设计要求项目图：
   - 改用纯文字 Hero + 项目 Meta + 少量正式像素主题装饰。
   - 装饰只能来自正式 Asset Pack。
4. 页面主体顺序建议：
   Meta → Intro → Objective → Challenge → Actions → Outcomes → Learnings → CTA
5. Outcome 有数字时优先做数据卡，例如：
   - 20W+ GMV
   - 50%+ 利润率
   - 1000+ 海外社媒内容
   - 8000+ 涨粉
6. 后续 gallery 有内容后，组件自动显示，不重做页面。
